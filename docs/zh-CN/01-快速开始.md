# 01 · 快速开始

> [English](../en/01-quick-start.md) | [简体中文](01-快速开始.md)

在任意 Docker 环境部署 DeepSeek Harness（DSH）。

## 1. 前置要求

- 支持 `docker compose` v2 的 Docker Engine ≥ 20.10。
- 能够拉取 `node:24-slim`（国内网络建议配置 registry 镜像加速，见 [05](05-平台差异.md)）。
- 一个 DeepSeek API Key（或其他兼容模型 API）。

## 2. 目录结构

```
dsh-docker/
├── docker-compose.yml   # 部署配置
├── Dockerfile           # 基础镜像（可自行构建或直接用 ghcr.io 镜像）
├── entrypoint.sh        # 容器入口
└── .env.example         # 环境变量模板
```

## 3. 安装步骤

### 3.1 拉取仓库并配置

```bash
git clone https://github.com/steven-stack-s/dsh-docker.git
cd dsh-docker

cp .env.example .env
# 编辑 .env，至少填写：
#   DEEPSEEK_API_KEY=sk-你的密钥
# 其余变量有默认值，可按需调整（端口、数据目录、资源限制等）
```

> `.env` 已被 `.gitignore` 忽略，密钥不会进入 git。

### 3.2 启动

```bash
docker compose up -d
```

首次启动时 `entrypoint.sh` 会从镜像内 seed（`/opt/dsh-seed`）把 dsh+pnpm 复制到挂载卷 `/opt/dsh`，秒级完成、离线、版本固定（健康检查 `start_period` 已缩短到 60s）。

### 3.3 查看启动日志

```bash
docker logs dsh --tail 15
```

预期输出：

```
[entrypoint] 首次启动：准备 @deepseek-ai/dsh 到挂载卷 /opt/dsh ...
[entrypoint]   从镜像内 seed (/opt/dsh-seed) 复制到 /opt/dsh
[entrypoint] DSH 已就绪: /opt/dsh/bin/dsh
[entrypoint] 启动 socat 转发: 0.0.0.0:3080 -> 127.0.0.1:3081
[entrypoint] 启动 dsh web (内部 127.0.0.1:3081)
dsh web: http://127.0.0.1:3081
```

- 不应出现 "opening the default browser"（已加 `--no-open`）。
- 启动瞬间 socat 的 `Connection refused` 属正常（dsh 尚未就绪），dsh 起来后消失。

## 4. 创建首个管理员

DSH 的 Web 界面允许创建首个管理员，但该操作**仅限 loopback 提交**（防远程抢注）。在**宿主机**上执行（端口映射后 `127.0.0.1:3080` 即容器入口）：

```bash
curl -s -X POST http://127.0.0.1:3080/auth/bootstrap \
  -H 'Content-Type: application/json' \
  -d '{"username":"你的用户名","password":"你的密码"}'
# 期望返回 {"ok":true,...,"user":{...}}
```

没有 curl 的宿主机可用 SSH 隧道方式（见 [02](02-认证与远程访问.md)）。

## 5. 验证

- 浏览器打开 `http://<主机IP>:3080`，用刚创建的账号登录。
- 设置 → 模型，确认 API Key 已生效。
- `docker ps` 中 `dsh` 容器状态为 healthy（首次启动从 seed 复制，秒级就绪，starting 时间很短）。

## 6. 停止 / 卸载

```bash
docker compose down          # 停止并移除容器（数据保留在 ./dsh ./programs ./workspace）
docker compose down -v       # ⚠️ 连同匿名卷一起删除（本方案未用命名卷，数据在挂载目录，不受影响）
rm -rf dsh programs workspace # 彻底删除数据
```
