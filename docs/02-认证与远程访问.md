# 02 · Authentication & Remote Access / 认证与远程访问

The default configuration is **intranet direct access** (no auth plugin installed): port `3080` is mapped to the host, reachable only within the LAN.
For **remote access across networks** (public internet, off-site), follow this guide to add authentication and use a reverse proxy.

默认配置为**内网直连**（不装认证插件）：`3080` 端口映射到宿主机，仅局域网内可访问。
如果你需要**跨网络远程访问**（公网、异地），请按本指南加装认证并配合反向代理。

## 1. Access Overview / 访问方式总览

| 方式 Method | 安全性 Security | 适用场景 Use case |
|---|---|---|
| 本机访问（`127.0.0.1:3080`） Local access (`127.0.0.1:3080`) | 最高 Highest | 部署在同一台机器的浏览器 Browser on the same machine |
| 内网直连（`http://<内网IP>:3080`） Intranet direct access (`http://<内网IP>:3080`) | 高（无认证，依赖内网隔离） High (no auth, relies on intranet isolation) | 局域网内使用 LAN usage |
| SSH 隧道 SSH tunnel | 高（加密） High (encrypted) | 单人在外临时访问 Temporary single-user access from outside |
| 反向代理 + dsh-remote 认证 Reverse proxy + dsh-remote auth | 高（认证层 + HTTPS） High (auth layer + HTTPS) | 长期远程访问 Long-term remote access |

> Browser limitation: some features of `dsh web` (e.g. `crypto.randomUUID`, settings) require a **secure context**
> (HTTPS or localhost). If you hit related errors when accessing the intranet directly by IP, that is the browser's security
> policy; use `localhost`, an SSH tunnel, or HTTPS via a reverse proxy instead.
>
> 浏览器限制：`dsh web` 的部分功能（如 `crypto.randomUUID`、settings）要求**安全上下文**
> （HTTPS 或 localhost）。内网通过 IP 直连时若遇到相关报错，属浏览器安全策略，
> 可用 `localhost` 访问、SSH 隧道或反向代理 HTTPS 解决。

## 2. Add dsh-remote Authentication (Optional, Recommended for Remote Access) / 加装 dsh-remote 认证（可选，推荐远程访问时启用）

The [dsh-remote](https://github.com/xgone/dsh-remote) plugin provides **username/password + MFA (TOTP)** authentication;
`/api`, WebSocket, and privileged methods are only allowed after a successful login.

[dsh-remote](https://github.com/xgone/dsh-remote) 插件提供**账号密码 + MFA（TOTP）**认证，
登录通过后才放行 `/api`、WebSocket 与特权方法。

```bash
# Install the plugin (plugin & account data go into the /data/dsh volume, survive container rebuilds) / 安装插件（插件与账号数据写入 /data/dsh 卷，容器重建不丢）
docker exec dsh dsh plugin --profile web add @xgone/dsh-remote
docker restart dsh
```

### 2.1 Create the First Admin (loopback Only, to Prevent Remote Registration) / 创建首个管理员（仅限 loopback 提交，防远程抢注）

Run on the **host machine**:

在**宿主机**上执行：

```bash
curl -s -X POST http://127.0.0.1:3080/auth/bootstrap \
  -H 'Content-Type: application/json' \
  -d '{"username":"你的用户名","password":"你的密码"}'
# Expected response: {"ok":true,...,"user":{...}} / 期望返回 {"ok":true,...,"user":{...}}
```

> Skip this step if you already created an admin in [01-快速开始](01-快速开始.md).
>
> 若已按 [01-快速开始](01-快速开始.md) 创建过管理员，则跳过此步。

### 2.2 Log In and Enable MFA / 登录并开启 MFA

- Visit `http://<主机>:3080` and log in with your account / 访问 `http://<主机>:3080`，用账号登录
- Settings → Login & Account → Two-factor authentication (MFA) → scan the QR code with Google Authenticator / 1Password / 设置 → 登录与账号 → 双重验证（MFA）→ 用 Google Authenticator / 1Password 扫码
- **MFA is mandatory**: if exposed to the public internet via a reverse proxy, the auth layer is the only line of defense / **MFA 必开**：若通过反向代理暴露到公网，认证层是唯一防线

## 3. SSH Tunnel (Temporary Single-User Access from Outside) / SSH 隧道（单人在外临时访问）

```bash
# Local port forwarding: map remote 3080 to local 3080 / 本地端口转发：把远程 3080 映射到本机 3080
ssh -L 3080:127.0.0.1:3080 你的账号@主机IP
# Then open http://127.0.0.1:3080 in the browser / 然后浏览器打开 http://127.0.0.1:3080
```

Works wherever Windows/Mac/Linux ship with a built-in `ssh` — no extra configuration needed.

适合 Windows/Mac/Linux 自带 ssh 的场景，无需额外配置。

## 4. Reverse Proxy + HTTPS (Long-Term Remote Access, Recommended) / 反向代理 + HTTPS（长期远程访问，推荐）

Using Caddy (automatic HTTPS) as an example; Nginx works the same way:

以 Caddy（自动 HTTPS）为例，Nginx 同理：

```bash
# Caddyfile (the domain must resolve to the host; ports 80/443 open) / Caddyfile（域名需解析到主机；80/443 端口开放）
你的域名.com {
    reverse_proxy 127.0.0.1:3080
}
```

```bash
# Run Caddy with Docker / 以 Docker 运行 Caddy
docker run -d --name caddy \
  -p 80:80 -p 443:443 \
  -v /path/to/Caddyfile:/etc/caddy/Caddyfile \
  -v caddy_data:/data \
  caddy:2
```

> Before exposing through a reverse proxy, make sure dsh-remote is installed and MFA is enabled (see Section 2).
>
> 反代前务必确认已加装 dsh-remote 并开启 MFA（见第 2 节）。

## 5. Security Checklist / 安全清单

- [ ] Remote access: strong password + **MFA (TOTP)** / 远程访问时：强密码 + **MFA（TOTP）**
- [ ] Do not map `3080` directly to the public internet (when no auth is added) / 不要把 `3080` 直接映射到公网（未加认证时）
- [ ] Third-party plugins have full permissions; review their source before installing / 第三方插件有完整权限，安装前查看源码
- [ ] Back up regularly (see [03-升级与维护](03-升级与维护.md)) / 定期备份（见 [03-升级与维护](03-升级与维护.md)）
