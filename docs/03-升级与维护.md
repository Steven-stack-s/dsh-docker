# 03 · Upgrade & Maintenance / 升级与维护

## 1. Upgrade DSH (No Image Rebuild) / 升级 DSH（无需重建镜像）

Core design of this setup: DSH is installed into the volume `/opt/dsh`, so upgrading = an npm operation inside the container:
本方案的核心设计：DSH 程序装在卷 `/opt/dsh`，升级 = 容器内 npm 操作：

```bash
docker exec dsh npm install -g @deepseek-ai/dsh@<新版本>
docker restart dsh
```

Check the current version:
查看当前版本：

```bash
docker exec dsh dsh --version
```

> Only rebuild the image when the base environment changes (Node major version / system dependencies):
> `docker build -t <你的仓库>/dsh-docker:1 .` and update `DSH_IMAGE` in `.env`.
> 只有当基础环境变化（Node 大版本 / 系统依赖）时才需要重建镜像：
> `docker build -t <你的仓库>/dsh-docker:1 .` 并更新 `.env` 的 `DSH_IMAGE`。

## 2. Install / Remove Plugins / 安装 / 卸载插件

```bash
docker exec dsh dsh plugin --profile web add <包名>
docker exec dsh dsh plugin --profile web remove <包名>
docker restart dsh
```

Plugins and data are written to the `/data/dsh` volume, and survive container rebuilds/restarts.
插件与数据写入 `/data/dsh` 卷，容器重建/重启不丢。

## 3. Change the API Key / 更换 API 密钥

```bash
# Edit .env, change DEEPSEEK_API_KEY, then: / 编辑 .env，修改 DEEPSEEK_API_KEY 后：
docker compose up -d
```

## 4. Check Status and Logs / 查看状态与日志

```bash
docker ps | grep dsh              # container status (healthy / starting / unhealthy) / 容器状态（healthy / starting / unhealthy）
docker logs dsh --tail 100        # logs / 日志
docker stats dsh                  # resource usage / 资源占用
```

## 5. Backup / 备份

**Just back up the whole deployment directory** (program + data + configuration are all inside):
**备份整个部署目录即可**（程序 + 数据 + 配置全在里面）：

```bash
cd <部署目录>        # directory containing docker-compose.yml / 含 docker-compose.yml 的目录
tar czf dsh-backup-$(date +%Y%m%d).tar.gz dsh programs workspace .env
```

To restore: extract the backup back into the original directory and run `docker compose up -d`.
恢复：把备份解压回原目录，`docker compose up -d` 即可。

> The most important part of the data is `dsh/` (DSH_HOME: sessions, configs, plugins, credentials, Hindsight memory bank).
> `workspace/` is the agent workspace; back it up as needed.
> 数据中最重要的是 `dsh/`（DSH_HOME：会话、配置、插件、凭据、Hindsight 记忆库）。
> `workspace/` 是 agent 工作区，按需备份。

## 6. Update the Image (When the Base Environment Changes) / 更新镜像（基础环境变化时）

```bash
docker compose pull        # pull the new ghcr.io image / 拉取新版本 ghcr.io 镜像
docker compose up -d       # rebuild the container / 重建容器
```
